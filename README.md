# CSSECDV-Machine-Project

Secure Web Development machine project for De La Salle University. The course provides a Java Swing application with SQLite; our task is to implement its required security controls and role-based features.

The integrated authentication, authorization, catalog, account administration, and audit features are on `main`. The [readiness record](docs/TODO.md) maps the checklist to the latest test evidence and its limits.

For the prepared standalone application, follow the [distribution instructions](app/submission/README.md). The source project is in `app/`; use the prepared distribution rather than the starter-fixture database generated by a normal build.

## Run the prepared demo

The prepared distribution needs a Java 21 runtime. Download the latest release ZIP, extract it, and run the JAR from its distribution folder so it uses the prepared database:

```bash
cd CSSECDV-Machine-Project/app/submission/distribution
java -jar CSSECDV.jar
```

The ZIP includes `DEMO-CREDENTIALS.txt` with the four demo accounts. The JAR, database, and SQLite JDBC library must stay together in `app/submission/distribution/`.

## Build from source

Install JDK 21 and Apache Ant, then run from the project root:

```bash
ant -f app/build.xml clean init-db jar
```

This creates `app/dist/` for development and uses the course starter database. For setup details and NetBeans instructions, see [the development guide](docs/development.md).
