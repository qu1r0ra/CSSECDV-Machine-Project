# Architectural decisions

Architectural decision records (ADRs) live in `docs/adr/`.

- Before proposing architectural changes, read existing ADRs relevant to the proposal.
- If a proposal conflicts with an ADR, identify the record and explain why the decision should be reconsidered.
- When recording a resolved architectural decision, document its context, the decision, and its consequences.
- Create `docs/adr/` when the first decision is recorded. If it is absent during exploration, proceed silently.
